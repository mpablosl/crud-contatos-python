# 📇 CRUD de Contatos com Python, Flask e SQLite

Este é um projeto simples de **CRUD (Create, Read, Update, Delete)** feito com **Python**, **Flask** e **SQLite3**, com o objetivo de praticar e demonstrar como criar uma aplicação web básica com banco de dados.

---

## 🚀 Funcionalidades

- ✅ Adicionar contatos (nome, telefone, e-mail)
- ✅ Visualizar todos os contatos
- ✅ Editar dados de um contato
- ✅ Deletar contatos existentes
- ✅ Interface web com HTML simples (pronto para integrar Bootstrap)
- ✅ Estrutura pronta para melhorias: filtros, busca, responsividade

---

## 🧰 Tecnologias utilizadas

- Python 3
- Flask
- SQLite3
- HTML5 / CSS3
